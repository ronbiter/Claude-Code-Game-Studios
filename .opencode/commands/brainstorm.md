# Brainstorm — Game Concept Ideation

Guided creative exploration to develop a game concept.

## Step 1: Creative Discovery

Start conversationally to understand the user:

**Taste profile**:
- What 3 games have you spent the most time with? What kept you coming back?
- Are there genres you love? Genres you avoid? Why?
- What kind of experience do you most want players to have? (Challenge & Mastery / Story & Discovery / Expression & Creativity / Relaxation & Flow)

**Practical constraints**:
- What's your realistic development timeline? (Weeks / Months / 1-2 years)
- Where are you in your dev journey? (First game / Shipped before / Professional)

## Step 2: Concept Generation

Generate **3 distinct concepts** in different directions:

**Technique 1: Verb-First Design**
Start with core player verb (build, fight, explore, solve, survive, create, manage) and build outward.

**Technique 2: Mashup Method**
Combine: [Genre A] + [Theme B]. The tension creates the unique hook.

**Technique 3: Experience-First Design**
Start from desired player emotion and work backward to mechanics.

For each concept, present:
- Working Title
- Elevator Pitch (1-2 sentences)
- Core Verb (most common player action)
- Core Fantasy (emotional promise)
- Unique Hook ("Like X, AND ALSO Y")
- Estimated Scope (small/medium/large)

Ask user which concept resonates, or to combine elements.

## Step 3: Core Loop Design

For the chosen concept:

**30-Second Loop** (moment-to-moment):
- What's the primary feel of the core action?
- What makes it feel good? (audio, visual, timing, tactics)

**5-Minute Loop** (short-term goals):
- What structures moment-to-moment play into cycles?

**Session Loop** (30-120 minutes):
- What does a complete session look like?
- Natural stopping points?

## Step 4: Game Pillars

Collaboratively define **3-5 pillars**:
- Each pillar: name + one-sentence definition + design test
- Each pillar should feel like it creates tension with others

Define **3+ anti-pillars** (what this game is NOT):
- Frame as: "We will NOT do X because it would compromise Y pillar"

## Step 5: Player Type Validation

Based on Bartle taxonomy:
- Who will LOVE this game? (Achievers, Explorers, Socializers, Competitors, Creators)
- Who is this NOT for?

## Step 6: Scope and Feasibility

- Target platform: PC / Mobile / Console / Web
- Engine preference
- MVP definition
- Biggest risks

## Step 7: Write Document

Use template `.agents/docs/templates/game-concept.md` to write the concept.

Ask user approval before writing to `design/gdd/game-concept.md`
