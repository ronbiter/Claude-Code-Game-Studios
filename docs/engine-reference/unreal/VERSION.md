## Knowledge Gap Warning

LLM training data covers up to ~5.3. Versions 5.4–5.7 introduced significant changes the model does NOT know about. Always search engram memory for "Unreal Engine 5.7 version reference" before suggesting UE APIs.

## Breaking Changes (5.3 → 5.7)
- **Substrate Material System**: New framework replacing legacy materials
- **PCG**: Production-ready, major API changes
- **Megalights**: Millions of dynamic lights
- **Animation Authoring**: New rigging/animation tools
- **AI Assistant**: In-editor AI guidance (experimental)

## Deprecated
- Legacy Material System → migrate to Substrate
- Old PCG API → use new production-ready PCG API (5.7+)
